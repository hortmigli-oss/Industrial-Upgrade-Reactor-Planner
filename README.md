# Industrial Upgrade Reactor Planner

Веб-планировщик и симулятор ядерных реакторов из Minecraft-мода Industrial Upgrade.

## Цель проекта

Создать веб-приложение, максимально близкое по возможностям и удобству использования к [Ic2ExpReactorPlanner](https://github.com/MauveCloud/Ic2ExpReactorPlanner), но с физикой и правилами реакторов из [Industrial Upgrade](https://github.com/ZelGimi/industrialupgrade).

Главная цель — получить удобный редактор схем реактора, симуляцию по тикам, отображение тепла/генерации/радиации/повреждений, сохранение схем и набор автоматических тестов, подтверждающих совпадение расчётов с исходным модом.

## Технологический стек

- TypeScript
- React
- Vite
- Vitest
- Zustand — состояние UI, при необходимости
- Recharts — графики, при необходимости

Java и отдельный backend на первом этапе не используются. Физический движок работает как независимый TypeScript-модуль и не зависит от React или DOM.

## Основные требования

- Перенести физику Industrial Upgrade в TypeScript.
- Сохранить порядок и смысл расчётов исходного мода.
- Поддержать типы реакторов Industrial Upgrade.
- Поддержать компоненты реактора и их взаимодействия.
- Реализовать пошаговую симуляцию.
- Реализовать удобный редактор сетки.
- Реализовать графики параметров.
- Реализовать сохранение и загрузку схем.
- Реализовать share-код.
- Реализовать автоматические golden tests против эталонных результатов Industrial Upgrade.

## Основные источники

Репозиторий мода:

Репозиторий планировщика:

## Архитектура

```text
industrial-upgrade-reactor-planner/
├── src/
```

Принципиальное разделение:

```text
Industrial Upgrade source
        ↓
  модель и формулы
        ↓
TypeScript simulation core
        ↓
    React UI
```

## Правило тестирования

Каждая значимая часть физики должна иметь тесты.

Порядок работы:

```text
реализация
→ unit-тест
→ integration-тест
→ сравнение с Industrial Upgrade
→ исправление расхождений
→ следующий этап
```

Физический движок считается корректным только после прохождения golden tests на заранее зафиксированном наборе схем.
