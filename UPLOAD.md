# Загрузка в GitHub

Репозиторий: https://github.com/hortmigli-oss/industrial-upgrade-reactor-planner

Структура файлов:

```text
README.md
docs/development-plan.md
```

Команды:

```bash
git clone https://github.com/hortmigli-oss/industrial-upgrade-reactor-planner.git
cd industrial-upgrade-reactor-planner
cp /path/to/README.md ./README.md
mkdir -p docs
cp /path/to/development-plan.md ./docs/development-plan.md
git add README.md docs/development-plan.md
git commit -m "docs: add project goals and development plan"
git push origin main
```
